# Checklist para publicar o primeiro projeto no GitHub

## Antes de publicar
- [ ] Confirmar que os dados podem ser divulgados.
- [ ] Remover dados pessoais, confidenciais, credenciais e caminhos locais desnecessários.
- [ ] Enviar a pasta complementar do projeto PBIP ou avaliar se é melhor compartilhar o PBIX.
- [ ] Conferir se o projeto abre em outro local sem depender de arquivos locais ausentes.
- [ ] Tirar uma captura de tela legível do dashboard.
- [ ] Confirmar os nomes dos indicadores, filtros e páginas.
- [ ] Documentar as etapas realmente realizadas.

## No repositório
- [ ] Nome claro, por exemplo: portfolio-power-bi
- [ ] README.md preenchido e sem campos provisórios.
- [ ] Pasta imagens com a captura do dashboard.
- [ ] Ficha do projeto concluída.
- [ ] Arquivos completos do projeto, se forem seguros e necessários.
- [ ] Link do LinkedIn, se desejar.

## Após publicar
- [ ] Abrir o repositório em janela anônima para conferir o que está público.
- [ ] Testar links e imagens.
- [ ] Adicionar o link ao currículo e ao LinkedIn.
- [ ] Não usar “Publicar na Web” no Power BI sem entender que o relatório e os dados subjacentes podem ficar acessíveis publicamente.
